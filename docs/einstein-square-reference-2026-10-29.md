## 地图关系

- 源要素：[OSM way/98865830](https://www.openstreetmap.org/way/98865830)，名称“爱因斯坦广场”，`leisure=park`，类别 green。来源几何时间戳为 2013-07-27。
- 原范围约为经度 114.4298655–114.430242、纬度 30.5162249–30.5169124；是南北窄长、北端圆头的范围，最大宽度约 36 m、南北约 76 m。
- 地图的 `way/98831427` 从西向东穿过源 park 北部，外围另有 `way/98831417` 和东侧道路。新铺装先扣除源道路廊道、建筑、水体和运动场，再只保留**包含真实雕像位置的南侧连通面**。北侧帽形区域交回原草地和植被层，不再整块铺石板。没有为了照片构图删除或挪动道路。
- 雕像影像配准参考点 **[114.4300345, 30.5164233]**（EPSG:4326），也保留为圆形铺装中心。用户随后要求雕像再向南一点，模型仅将雕像沿校园 +Z 微调 **3 m**，当前模型坐标约 **[114.4300344976, 30.5163962391]**；这是用户现场校正，不是新增测量值。旧点 `[114.4301, 30.51682]` 约在其北侧 44 m，处于横路北方的草地，是此前“先避路后找位置”的错误推定，已移除。
- 雕像面朝广场南端，前轴参考 `[114.430019, 30.516245]`。局部 yaw 约 -0.075 rad，与狭长场地轴线一致，面向东园食堂一侧。不是机械朝向某一个食堂坐标。
- 白廊北院有独立中心参考 **[114.430055, 30.516601]**，距原影像雕像参考点约 19.8 m，距南移后雕像约 22.8 m；其北半圆柱架最远约在南移后雕像北方 34 m。**不再把长廊硬绑在雕像身后 4.8 m**。
- 这些坐标是影像配准估计，保留 `measured:false`；七位小数只是计算与重复定位的存储格式，不表示厘米级精度。原 OSM 轮廓也不是现状测绘，不超出原场地任意扩大大广场。
- `plan.polygons` 仅排除南侧铺装上的随机植被；北侧原草地继续生成。内部弧形绿化由设施层生成，宿舍与树林仍保留源模型。

## 模型与可行走性

- 黑灰基座宽 2.9 m、深 2.3 m、高约 1.8 m；上方头像和手部连为一体，整体高度上限 7.3 m。**全部尺寸是照片比例估计，不宣称 1:1 测绘。**
- 头像有独立脸部起伏、凹眼眶、鼻梁、眼睑、胡须、发束和弯曲手指；没有把照片贴在平面板上。雕塑仍属照片参考的程序化近似，不能替代近景多视角扫描和艺术家精雕。
- 北侧白廊按俯视轮廓改为半圆弧形，外径约 25.4 m、开放环梁与径向顶肋、22 根方柱；内侧为半圆种植地，朝南两段弧形花池。两侧各 6 级台阶，单级 0.12 m，连接高 0.72 m 的弧形平台；内外弧挡边与台阶开口匹配。柱距、平台高度仍是照片估计。
- 基座、上部雕塑、白色廊柱、花池和平台挡边有分高度碰撞。主场可以正常从既有道路绕行和经两侧台阶进入廊架。
- 南侧圆形铺装增加同心石带，保留灰红石板前场；主地面、圆场和石带裁成**互不重叠**的多边形，统一位于接触面下 0.015 m，不用叠加近共面圆盘造成闪烁。
- 同材质合批；当前模型（无浏览器碑题画布时）10 次绘制、28,223 三角形。廊架和雕塑距镜头超过 550 m 隐藏，广场低成本地面仍保留。未引入外部大模型、图片请求或动画循环。

## 接入

```js
import { createEinsteinSquare } from './einstein-square.js';
const square = createEinsteinSquare(THREE, model, { frame, geoToLocal });
sceneGroup.add(square.group);
// 合并，不覆盖已有建筑、运动场与桥梁的基础设施。
model.architectureInfrastructure.barriers.push(...square.infrastructure.barriers);
model.architectureInfrastructure.walkSurfaces.push(...square.infrastructure.walkSurfaces);
// 与既有更新/销毁生命周期一起调用。
square.update(camera);
square.dispose();
```

返回 `group, plan, infrastructure, update(camera), dispose, counts`；`plan.arrival` 为从南侧真实铺装导出的玩家落点 `{x,z,y,yaw,pitch}`，经过场地和全部碰撞体检查；缺源要素或缺投影时给空层，不挪到假定原点。`plan.inspection` 和 `plan.pedestrianInspection` 提供鸟瞰及行人视高检查位置。不要直接写死本文件示例数值代替已有 frame。

## 用户现场校正：雕像再向南 3 m

用户在确认“横路南侧、面向东园食堂”后要求雕像“再往南移动一点”。本次只对雕像组件施加校园局部坐标 `Δx=0, Δz=+3 m, Δy=0`，这是按用户反馈选取的小幅校正，不作为实测结论。

- 像、手部、底座、铭牌及对应分高度碰撞同步移动，投影阴影随实际几何移动；朝向保持 `yaw=-0.07504575162698456`，没有因朝向目标点重新计算而扭转。
- 圆形铺装与同心石带保持原影像中心不动；白廊、台阶、花池、植物、道路及原 GeoJSON 都保持原世界位置。局部白廊数值随新的雕像坐标原点变换，最终校园世界坐标不变。
- 导览出生点、观察目标和摄影位置随雕像向南 3 m，重新通过铺装范围与碰撞检查；出生点与像仍保留原观察距离。
- 只修改 `src/einstein-square.js`、`tests/einstein-square.test.mjs` 和本文。语法检查、5 项模块测试通过，补验精确 3 m 位移、原朝向、独立圆场中心、白廊世界坐标不动和报告坐标一致；10 次绘制、28,223 三角形不变。此次没有另做浏览器验收，交由根任务联调。
