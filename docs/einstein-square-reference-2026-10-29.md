## 地图关系

- 源要素：[OSM way/98865830](https://www.openstreetmap.org/way/98865830)，名称“爱因斯坦广场”，`leisure=park`，类别 green。来源几何时间戳为 2013-07-27。
- 原范围约为经度 114.4298655–114.430242、纬度 30.5162249–30.5169124；是南北窄长、北端圆头的范围，最大宽度约 36 m、南北约 76 m。
- 地图的 `way/98831427` 从西向东穿过广场北部，外围另有 `way/98831417` 和东侧道路。新铺装主动扣除源道路廊道、建筑、水体和运动场范围。没有为了照片构图删除或挪动已有道路。
- 因此雕塑与廊架位于北侧帽形区域，南侧保留狭长前场。当前头像参考位置 **[114.4301, 30.51682]**，面向南、随广场轴线轻微旋转。此为照片与可用地图范围的**估计配准**，并非实测雕像点位。
- 宿舍与树林继续使用现有源模型。`plan.polygons` 可作为植被排除范围，防止随机树或灌木生长到铺装中央；不额外再生成一圈无依据的大树。

## 模型与可行走性

- 黑灰基座宽 2.9 m、深 2.3 m、高约 1.8 m；上方头像和手部连为一体，整体高度上限 7.3 m。**全部尺寸是照片比例估计，不宣称 1:1 测绘。**
- 头像有独立脸部起伏、凹眼眶、鼻梁、眼睑、胡须、发束和弯曲手指；没有把照片贴在平面板上。雕塑仍属照片参考的程序化近似，不能替代近景多视角扫描和艺术家精雕。
- 后方白色廊架约 19 m 宽，开放梁架、14 根方柱、纵梁与顶肋；两侧各 6 级台阶，单级 0.12 m，连接高 0.72 m 平台。台阶、平台和碰撞分别对齐，平台侧后方有挡边，避免从侧面自动跳升到高处。
- 基座、上部雕塑、白色廊柱、花池和平台挡边有分高度碰撞。主场可以正常从既有道路绕行和经两侧台阶进入廊架。
- 灰红铺装沿地图形状裁剪；平面渲染高程比角色接触面低 0.015 m，避免地面闪烁和脚部穿插。
- 同材质合批；当前模型（无浏览器碑题画布时）8 次绘制、少于 45,000 三角形。廊架和雕塑距镜头超过 550 m 隐藏，广场低成本地面仍保留。未引入外部大模型、图片请求或动画循环。

## 接入

```js
import { createEinsteinSquare } from './einstein-square.js';
const square = createEinsteinSquare(THREE, model, { frame, geoToLocal });
sceneGroup.add(square.group);
// 合并，不覆盖已有建筑、运动场与桥梁的基础设施。
model.architectureInfrastructure.barriers.push(...square.infrastructure.barriers);
model.architectureInfrastructure.walkSurfaces.push(...square.infrastructure.walkSurfaces);
// 与既有更新/销毁生命周期一起调用。
square.update(camera);
square.dispose();
```

返回 `group, plan, infrastructure, update(camera), dispose, counts`；缺源要素或缺投影时给空层，不挪到假定原点。`plan.inspection` 和 `plan.pedestrianInspection` 提供鸟瞰及行人视高检查位置。不要直接写死本文件示例数值代替已有 frame。
