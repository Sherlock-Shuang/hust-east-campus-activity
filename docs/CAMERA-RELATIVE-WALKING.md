# 按镜头方向步行 — 2026-10-28

W/S、A/D 和手机摇杆采用镜头在地面的前后、左右方向，与蜘蛛侠控向保持一致。人物平滑转向行进方向，位移无需等人物转身完成；斜向输入归一化，不额外提速。改变视角时，按住的移动输入即时采用新方向。第一、第三人称相同。

步行期间镜头不自动追随人物朝向，松键后也保持视线。C 回正以按下时的人物朝向为固定目标，避免侧移时镜头不停追转。作品返回快照同时保存镜头逻辑方向和世界速度，避免只恢复画面一帧、下一帧又跳转。
