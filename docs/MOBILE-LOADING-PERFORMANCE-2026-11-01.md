# 冷启动与手机移动优化 · 2026-11-01 第二轮

基线为 `f6f8f41`，在已完成第一轮游戏/图书馆/晚言优化之上增量修改。原地图、楼体、树木数量、交通模拟频率、碰撞、移动参数及作品运行包保持原样。没有重新上传生日礼物源码或私人资料。

## 本轮改动

- 封面静态画面和标题立即显示；约 8 MB 的可选影片在校园已就绪后才允许请求。立即进入时取消该请求；省流量或浏览器报告 2G/3G 时保留原静态美术。影片播放仍支持桌面/手机，离开、隐藏和减弱动态偏好正确暂停。
- 校园、道路和交通场景重复生成的同一套程序材质使用弱引用像素缓存；每个场景仍持有独立像素副本、纹理和材质。27 组像素与基线逐字节相等，不降低贴图尺寸，也不因缓存强引用留住已销毁场景。
- 生活区 NPC 路线的障碍筛选将不变的路线包围盒提前计算一次。原采样点、障碍范围、接纳条件和生成路线不变。
- 不透明静态实例保留 GPU 槽位，仅更新进入/离开视野的实例；分离的变化使用局部上传范围，最多 16 段，避免上传两处改动中间的大段不变数据。透明对象保持原顺序，完整导出恢复源顺序，拾取 ID 始终与实际矩阵对应。
- 湖岸植物将原平滑密度公式预先求逆，用平方距离判断同一个可见集合；数值临界点退回原公式。仍保留相同叶片、显示距离、近景数量和静态导出。叶片也复用稳定槽位和局部上传。

## 实测结果

同机已安装 Chrome，生产模式临时构建、独立浏览器环境、844×390 触摸视口、DPR2、CPU6倍限速、流畅画质；所有实际测量区间串行执行。通过真实开始按钮进入，真实按键移动；触屏测试使用真实触点执行浮动摇杆、拾取和升空。没有通过遥移代替移动距离。

冷启动额外使用80ms延迟、10Mbps吞吐和禁用浏览器缓存。临时Node服务器未压缩JavaScript，与公网CDN响应不同，所以这里的秒数只用于相同条件下的A/B，不代表公网或真机固定耗时。
