# 天空微信二维码

在 `/admin` 登录后，全场控制下方提供常驻的“天空二维码”区域。

- 活动结束时点击“在天空显示二维码”：观众收到现有实时活动状态，抬头可看到天空中的二维码。
- 户外步行或使用蜘蛛侠时，默认第三人称和第一人称都可直接观看头顶：电脑向上移动鼠标，手机在画面右侧向上拖动，无需先切换视角。活动暂停时保持已有视角，仍可看到天空二维码。
- 点击“收起二维码”：所有观众收起天空展示。
- 开关独立于暂停、活动阶段和作品开放。不会自动结束活动或把二维码作为通关条件。
- 手机与电脑的观众界面只显示天空中的 3D 二维码，没有扫码提示、按钮、原图弹窗或额外说明。
- 默认收起；刷新、重连和服务重启会继承主持人最后保存的状态。

天空和后台预览使用独立方形二维码 `public/images/activity/wechat-qr-cutout.png`（1254×1254 RGBA），静态路径 `/images/activity/wechat-qr-cutout.png`。已去除头像、昵称、位置及底部说明，保留二维码及白色扫码静区，渲染时用纯白静区衬底保证对比。使用内置 imagegen 提取；Apple Vision 解码结果与用户原 JPEG 一致。用户原图仍保存在 `public/images/activity/wechat-qr.jpg`，没有覆盖。更换二维码后需重新构建并核验实际扫码内容。

状态字段 `skyQrVisible` 是严格 boolean，旧状态缺省为 false。沿用原管理员鉴权、CSRF、expectedRevision、持久化和 SSE；观众不能控制全场开关。Node 端读取旧状态时补齐默认值，Serverless 的旧数据库状态可能暂缺字段，前端用 `=== true` 兼容。

`src/sky-qr.js` 持有独立活动场景平面，首次显示才加载贴图；贴图按比例显示、无光照和雾影响，无动画。二维码固定在操场中心正上方的世界坐标 `(428.44619, 2400, 58.80678)`，约 2400 米高、1200 米见方，水平朝向地面。所有玩家看到同一个空间位置；它不跟随玩家移动、转头或手机尺寸，也不会主动转动玩家镜头。使用正常深度检测，建筑和屋顶可遮住它。步行和蜘蛛侠第一、第三人称均支持仰头至约 86°。第三人称保持碰撞安全的相机位置，单独旋转观看方向，避免相机压向地面；切换视角、回正及返回活动时保持连续。显示时暂停遮罩透明且不显示暂停文字，暂停本身仍会冻结玩家操作。隐藏后复用贴图，销毁释放资源，迟到加载不会重新显示；加载失败后主持人收起再显示可重试。`isOpen` 保持为 `false`，兼容活动生命周期接口，不再注册二维码键盘、焦点或点击事件。

验证：`npm run build` 后运行 `scripts/verify-sky-qr.mjs`。脚本使用临时数据目录、随机测试密码及隔离端口，验证实际校园/后台、多观众同步、刷新重连、暂停、收起、手机横竖屏、固定几何尺寸以及没有观众二维码 DOM 提示，不修改真实活动数据。可用 `PLAYWRIGHT_MODULE`、`CHROME_EXECUTABLE` 指定已安装运行环境。

## 常驻群二维码

QQ 群卡片使用原图 `public/images/activity/hust-ai-builders-group.jpg`，与个人微信天空码独立。由 `src/field-group-qr.js` 放置在韵苑十六栋（食堂往东第二栋）西侧楼顶上方 `(650, 64, -105.95518)`，朝西面向食堂，宽 32 米，保留原群卡的比例和扫码静区。高度避开前方五栋的遮挡；按距离懒加载，随建筑图层显示，不受天空个人码开关影响。
