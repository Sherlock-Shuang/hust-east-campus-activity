# 手机横屏与触控操作

手机浏览器打开观众地址，填写昵称后横放手机。触屏设备自动显示控件；带鼠标的混合设备可点击左上角「触控」。不需要下载应用。原电脑键盘、鼠标和手柄操作继续保留。

## 操作

- 左下摇杆移动，离中心越远输入越大。步行按镜头方向走，车辆摇杆控制前进、倒退与转向。
- 在画面空白区域拖动转视角，可与摇杆及动作按钮同时使用。左上「视角」切第一／第三人称，「回正」恢复跟随。
- 靠近载具或战衣，右下出现「使用／穿上」；使用后显示退出按钮。下车仍要求停稳落地，游艇仍要求靠岸。
- 电动车／游艇提供加速和刹车；飞行器提供升降与悬停。特斯拉按住「喷气」提供升力，松开后受重力下落。
- 蜘蛛侠按「跳跃」起跳，按住「摆荡」保持当前锚点，松开再按才选新锚点。「更多」展开定点弹射、收丝、俯冲、空中特技；进阶动作不会自动挂丝。
- 全屏是可选功能。浏览器支持时申请全屏及横屏锁定；不支持或拒绝时仍可手动横放继续玩。竖屏提示可以关闭。

## 适配与运行边界

界面使用动态视口和刘海安全区，控件至少44px。旋转、切出浏览器、暂停、进入作品及切换载具均释放触控输入，返回不会自动继续走动或挂丝。活动公告、昵称窗口和作品返回栏保持可点击。

手机分辨率倍率上限1.25，阴影1024，关闭额外湖面倒影渲染，保留水面动画；移动中继续使用现有动态分辨率。校园几何、地理数据与物理没有精简替换。手机实际流畅度仍取决于GPU和温度；重型作品自身的兼容性独立于校园触控适配。

实现：`src/mobile-controls.js`、`src/mobile-controls.css`、`src/mobile-render-profile.js`，由现有 `player-experience.js` 和 `survey.js` 接入。没有更换服务端、部署平台或管理员状态。

## 验证

2026-10-28：应用内浏览器分别检查844×390、667×375、915×412横屏及390×844竖屏，实际使用摇杆、视角、战衣交互和展开动作；这些是桌面浏览器的响应式尺寸检查，不等于物理iPhone／Android实机验收。

输入测试模拟独立多触点、取消、旋转、暂停、合成click与全屏拒绝；玩家集成测试连接实际物理和镜头，验证松丝不重挂、喷气松开落下和附近车辆上下车。生产部署副本 `npm test` 共212项全部通过；主工程另运行镜头、鼠标锁定、实时客户端和蛛丝物理92项全部通过。`npm run build:vercel` 成功并生成70个作品运行资源。应用内浏览器全屏进入／退出、第一／第三人称切换也已实际操作。
