# 手机横屏与触控操作

手机浏览器打开观众地址，填写昵称后横放手机。触屏设备自动显示控件；带鼠标的混合设备可点击左上角「触控」。不需要下载应用。原电脑键盘和鼠标操作继续保留；当前校园入口未实现原生手柄输入。

## 操作

- 左下摇杆移动，离中心越远输入越大。步行与键盘共用镜头方向：向两侧推杆就横向行进，人物转身但镜头不跟转；松杆保持视线，右侧拖动可随时改变行进基准。车辆摇杆控制前进、倒退与转向。步行上限 3.2 m/s，加速 5.2 m/s；玩家电动车上限 7.5 m/s，刹车按键加强减速。
- 在画面空白区域拖动转视角，可与摇杆及动作按钮同时使用。左上「视角」切第一／第三人称，「回正」恢复跟随。
- 靠近载具或战衣，右下出现「使用／穿上」；使用后显示退出按钮。下车仍要求停稳落地，游艇仍要求靠岸。
- 电动车／游艇提供加速和刹车；飞行器提供升降与悬停。特斯拉按住「喷气」提供升力，松开后受重力下落。
- 蜘蛛侠按「跳跃」起跳，按住「摆荡」保持当前锚点，松开再按才选新锚点。电脑 **G** 对应的 **「定点弹射」常驻右下动作区**：先面向带「定点」标记的屋沿，按钮提示「屋沿已锁定」后点击，接近或停在屋沿时再点「跳跃」弹出。「更多」只收纳收丝、俯冲和空中特技。
- 全屏是可选功能。浏览器支持时申请全屏及横屏锁定；不支持或拒绝时仍可手动横放继续玩。竖屏提示可以关闭。

## 适配与运行边界

界面使用动态视口和刘海安全区，控件至少44px。旋转、切出浏览器、暂停、进入作品及切换载具均释放触控输入，返回不会自动继续走动或挂丝。活动公告、昵称窗口和作品返回栏保持可点击。

蜘蛛侠主动作区使用固定网格，定点弹射、跳跃、前冲与摆荡不用展开菜单就能操作。短横屏把进阶动作放在左上工具条下，避免盖住右侧目标提示；竖屏阶段引导留在动作区上方。关闭「更多」会释放藏起来的收丝／俯冲／特技，主动作区仍按住的摆荡不受影响。输入框获得焦点时释放旧摇杆与动作触点，手机键盘弹出后不会继续移动。画质选择使用16px字号，避免移动浏览器因小字输入控件放大视口。

手机分辨率倍率上限1.25，阴影1024，关闭额外湖面倒影渲染，保留水面动画；移动中继续使用现有动态分辨率。校园几何、地理数据与物理没有精简替换。手机实际流畅度仍取决于GPU和温度；重型作品自身的兼容性独立于校园触控适配。

实现：`src/mobile-controls.js`、`src/mobile-controls.css`、`src/mobile-render-profile.js`，由现有 `player-experience.js` 和 `survey.js` 接入。没有更换服务端、部署平台或管理员状态。
