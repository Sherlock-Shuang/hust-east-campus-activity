# 光电信息大楼 C118 报告厅：照片证据与室内模型

核对日期：2026-10-29。此文件描述本轮新增的独立室内模型；它不改动校园原始 GeoJSON、原移动系统、作品存档或部署目录。

## 房间身份

C118 是光电信息大楼的报告厅，可用于大规模讲座、毕业典礼和文艺活动，不能按普通教室套模。以下资料正文明确给出地点：

- [2023 级本科生开学典礼，2023-09-18](https://news.hust.edu.cn/info/1004/49824.htm)：说明活动发生于光电信息大楼 C118 报告厅。
- [武汉光电国家研究中心毕业季系列活动，2024-06-17](https://wnlo.hust.edu.cn/info/1090/12515.htm)：6 月 13 日毕业生党课在 C118 报告厅；这是已查看正面图片的交叉身份线索。
- [Ferenc Krausz 讲座，2024-05-28](https://news.hust.edu.cn/info/1002/52408.htm)：正文说明 C118 有 500 余位师生现场聆听。**这是该场活动的到场人数，不能据此认定准确固定席位数。**
- [C 区服务设施位置公告](https://wnlo.hust.edu.cn/info/1374/4231.htm)：C 区次入口一楼大厅存在 C118A 房间这一定位线索。它不提供 C118 完整建筑平面或门的地理坐标。
- [2025 年暑期工作会议](https://oei.hust.edu.cn/info/1091/9815.htm)：正文再次将会场定位在光电信息大楼 C118。该文后段小组研讨照片可能不在同一房间，未混入建模依据。

实际可见并进入模型的特征：

1. 舞台背景、两侧与上框连续使用浅金色木饰面；前缘明显向观众方向呈浅弧形。
2. 舞台左右各有短台阶，台前外侧各有灰色双扇门和绿色疏散标志。
3. 台后中央是宽屏；上方另有细长黑底信息屏；台后左右可见小门。
4. 两侧高处悬吊白色分节阵列音箱，连接至顶面的细吊杆可辨。
5. 侧墙浅灰，具有吸音饰面效果；顶面浅色并设嵌入式筒灯。
6. 座椅背板偏浅木色，软垫为深红色，前排有棕色长桌；台前可见黑色返听音箱和左侧讲台。

**这张照片未覆盖整个后半厅。** 模型中后墙、后排精确坡度、完整顶灯网格和每排准确座位数属于为了可漫游而补齐的视觉估计。没有擅加普通教室黑板、外窗或教室课桌。

## 尺度与布局边界

`src/opto-c118-interior.js` 中默认数值均以米表示，单位与现有玩家一致：

| 参数 | 默认值 | 依据/限制 |
| --- | ---: | --- |
| 房间宽 × 深 | 22 × 34 m | 视觉比例和约 500 人活动规模的估计，非实测 |
| 净高 | 9.6 m | 舞台人物与舞台框比例的视觉估计 |
| 座位 | 20 排 × (4 + 18 + 4) = 520 | 仅用于视觉密度，**不是实际席位总数** |
| 座位间距 | 0.57 m | 人体尺度建模参数 |
| 主过道宽 | 1.5 m | 为现有玩家留通行净宽；不能当作消防设计数据 |
| 排距/逐排高差 | 1.05 / 0.12 m | 后半厅缺少侧视照片；可配置 |
| 舞台高度/单级 | 0.72 / 0.18 m | 与照片短梯及人物比例相符的估计 |
| 室内基面 | Y = 0.14 m | 与现有玩家运动常量对齐 |

舞台朝向局部 −Z；默认入口取照片中能确认的左前双扇门。出生点为 `(-9.95, 0.14, -8.5)`，朝舞台及观众区斜向；出口触发点为 `(-11.15, 0.14, -8.5)`。门后仅保留很短的入口凹室，不伪造尚未查明的 C 区走廊路线。

## 模型与接入

```js
import { createOptoC118Interior } from './opto-c118-interior.js';
const hall = createOptoC118Interior(THREE);
scene.add(hall.group);
// hall.colliders: polygon + minHeight + height，Y 全部为绝对高度
// hall.walkSurfaces: polygon + surfaceY
// hall.spawn / exit / bounds / viewpoints
// 离开室内时先解绑运行层输入，再：
hall.dispose();
```

- `planOptoC118Interior(options)` 是无 Three.js/DOM 依赖的可序列化布局，用于导航与测试。
- `createOptoC118Interior(THREE, options)` 不请求网络、不建立监听器、不启动动画；实际进入/返回由主场整合层负责。
- 桌椅、墙面、台前、讲台均有独立碰撞；照片所示双门和主过道保持连通。
- 座位按组件实例化，默认 56 个 mesh 渲染节点，不为每个座位单独创建材质或 draw call；不投射实时阴影。墙/地/椅子接收场景阴影属性由宿主是否启用阴影决定。
- 模型内含半球光和 2 盏不投影点光；宿主不需要再叠加强环境光。
- 舞台、椅背采用 128×128 确定性程序木纹；墙体采用细颗粒/穿孔感吸音纹理；深红软垫采用织物纹理。共 3 张小型 DataTexture，无 DOM/Canvas，未挪用参考照片。椅背与靠垫使用共享圆角轮廓，避免硬方块边缘。
- 所有 GPU 资源由单一 `dispose()` 管理，重复调用安全。
- 宽度、排数、过道等参数有范围及几何净空校验，不能配置成座椅穿后墙或过道被压缩的布局。
- 未将报告厅与错误的 `relation/20970638` 绑定。外部新光电大楼由独立增量层处理。

## 本模块验证

命令：`node --test tests/opto-c118-interior.test.mjs`

2026-10-29：5 项通过。

1. 证据与估计边界可序列化，并显式保留未知项。
2. 使用正式 `createPlayerMotion` 检查默认入口、门口、前横通道、主过道、后排与舞台能够放下完整玩家碰撞体。
3. 使用正式运动逐帧走过主过道和两侧上台梯；没有超过 0.18 m 的单步高度抬升，座位和墙体挡住玩家。
4. 拒绝非法排数、高差和被挤占的过道配置。
5. 所有几何和实例矩阵有限；共享资源数量有界；独立布局与渲染碰撞一致；几何、材质及 3 张小纹理均释放且不重复。

以上是模型和运动逻辑验证，不能代替浏览器中的最终光照、触控、返回校园体验验收。实际浏览器结果由主任务的联调记录另行保存。
