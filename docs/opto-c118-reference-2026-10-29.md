- [Ferenc Krausz 讲座](https://news.hust.edu.cn/info/1002/52408.htm)：C118 当场有 500 余位师生；这不是固定座位容量证明。
- [C 区服务设施位置公告](https://wnlo.hust.edu.cn/info/1374/4231.htm)：C 区次入口一楼大厅有 C118A 房间定位线索，不能单独推导整厅平面图。

## 比例参数与不确定边界

src/opto-c118-interior.js 的单位为米。下表是本次按照片比例调整的默认值，**全部是建模估算，不能称为 1:1 测绘或消防座位图**。

| 参数 | 当前默认值 | 说明 |
| --- | ---: | --- |
| 内部宽 × 深 | 23.4 × 35.5 m | 按座椅、纵向阶梯与舞台比例估计 |
| 基面至顶面 | 10.8 m | 按后部抬高平台与顶梁净空估计 |
| 座席分区 | 前 10 排 + 后 10 排 | 照片有遮挡，准确排数未取得 |
| 每排座位 | 4 + 18 + 4，总计 520 | 视觉密度参数，不是校方容量数据 |
| 座位横向间距 / 排距 | 0.57 / 1.08 m | 人体尺度与游戏可通行参数 |
| 两条主纵向过道 | 各 1.55 m | 两侧墙边也有通道 |
| 横向中廊宽度 / 地面高度 | 1.80 / Y=2.66 m | 前后座席分区间平坦连续平台 |
| 前区每排高差 / 单踏步 | 0.28 / 0.14 m | 第 1 排不抬高 |
| 后区每排高差 / 单踏步 | 0.34 / 0.17 m | 不把整排高差当成一个台阶 |
| 最后一排地面 | Y=6.06 m | 比前地面高 5.92 m，照片比例估算 |
| 舞台相对高度 / 单级 | 0.72 / 0.18 m | 左右各 4 级，通往舞台侧边 |
| 前侧门 / 中侧门地面 | Y=0.14 / 2.66 m | 与对应平台的物理地面一致 |
| 侧门估算净宽 / 高 | 2.20 / 2.55 m | 四门共享参数 |
| 台后屏幕 | 9.8 × 6.0 m | 使用实拍较方的比例，保留视频表面 API |

原先“逐排升高 0.12 m、累计仅 2.28 m、没有中间横廊”的布局已被本轮实拍取代。旧文档称后半厅没有照片的限制也已解除；仍缺准确尺寸、座位表和完整连续空间影像。

用户已确认两条外部路线：**学院标识处台阶前的左侧门 → 直走 → 左手报告厅**；**另一东侧外门直接进入报告厅**。这些连接关系应保留。走廊长度、门位的精确地理坐标及室内外测量配准仍未取得。本模块只定义局部空间，外部连接由主场建筑层实施。

## 入口、导航与返回

局部舞台在 −Z。默认出生在中横廊左侧门内：(-10.65, 2.66, 3.51)，朝向略斜向舞台；位置避开椅子与护板。

- viewpoints.westEntry：中横廊左门内，与默认出生点一致。
- viewpoints.eastEntry：前右门内，(10.65, 0.14, -9.25)。
- entry、front、frontDoor、middle、rear 保留，便于原查看逻辑与验收。
- westEntry/eastEntry 仅为室内局部入口名，不宣称绝对地理朝向已测量。运行层负责与用户路线对应并保存实际外部返回位置。
- 四门都有 exits；旧 exit.id='c118-return' 继续指向左前门。
- crossedC118Door 同时检查门的左右侧、净宽与脚下高度（误差 < 0.23 m），不会在错误楼层或高处越过相同 X/Z 时退出。
- 门洞周围装饰板按完整宽度避让；抬高的门下墙仍为实体，门凹室与厅内平台同高。
- 桌椅、护板、墙面、舞台前缘、讲台、钢琴、琴凳与低凳都进入碰撞数据。两条主楼梯、两条墙边楼梯和两侧上台梯可用正式运动系统行走。

## 模型接入与性能

    import { createOptoC118Interior } from './opto-c118-interior.js';
    const hall = createOptoC118Interior(THREE);
    scene.add(hall.group);
    hall.update(camera);   // 按距离隐藏细小椅脚扣件和椅背号牌
    hall.update(null);     // 导出或静态查看时恢复细节
    // 离开前由运行层卸载输入/媒体，随后：
    hall.dispose();

- planOptoC118Interior(options) 无 Three.js / DOM 依赖，可序列化；colliders 使用 polygon、minHeight、height（绝对 Y），walkSurfaces 使用 polygon、surfaceY。
- 几何生成不建立监听器、不请求网络、不启动媒体。原有 videoScreen 返回值、对象名和默认隐藏行为保留；视频生命周期仍归 viewer，未修改本地视频文件。
- 座椅及重复构件实例化。验证限制为不超过 80 个 mesh、8000 个实例构件和 9 个独立 geometry；没有为 520 张椅子各建材质或实时投影。
- 椅背号牌和细小支脚分为 3 个距离区域，超过 13 m 隐藏；厅体、座椅轮廓、台阶、门与灯槽保持显示。
- 仅 3 张 128 × 128 DataTexture：低对比非周期木纹、浅灰吸音细颗粒、深红织物；启用 mipmap。降低舞台木纹和接缝对比，防止远处波浪摩尔纹。
- 半球光与 2 盏不投影点光保留，宿主避免重复叠加强环境光。梁体调整为深中灰。
- dispose() 幂等释放全部本模块的几何、材质和纹理，不处置由 viewer 所有的视频资源。
- 参数校验拒绝排数穿墙、过道过窄、异常阶高、后排净空不足等配置。
