## 可以确认的文字事实

- [2018-09-26 校方现场报道](https://wnlo.hust.edu.cn/info/1104/5092.htm)：总建筑面积约12万平方米，总高度约33米，**由南向北划分 A—H 八个结构单元**；提及500人报告厅、实验室与办公区。33米用于展示高度上限，不能称为实测各分区层高。该文没有证明报告厅内部每排座数、舞台尺寸或全部房门位置。
- [2017-11-30 校方封顶报道](https://wnlo.hust.edu.cn/info/1104/5031.htm)：连续W形、地上8层/地下2层，8个结构单元，东西约200米/南北约300米。较早[2017-03-17 简报](https://wnlo.hust.edu.cn/info/1104/5004.htm)写东西约90米/南北约290米；公开文字存在口径差异，因此本轮不将任一数字强行缩放现有地图轮廓，平面使用有稳定标识的 OSM 坐标。
- [2020 校方巡察公告](https://wnlo.hust.edu.cn/info/1374/4231.htm)将 C118A 与 **C区次入口一楼大厅**关联；[会议室预订说明](https://wnlo.hust.edu.cn/gdzx/ggfu/hysyd.htm)将 C111、C114、C115、C117、C118 归于 C区。未取得可配准的首层平面图。

中信设计院 2014 年方案页为10万平方米双塔方案，与校方建成的12万平方米、连续W形8层建筑及实景不一致，**不采用双塔方案当作建成外观**。部分 hust.edu.cn 图片直链返回 WAF 403；保留阻断记录，没有绕过权限或以返回的HTML伪装为照片。

## 数据、模型与接入

- `public/data/opto-southeast.geojson`：从本次公开 OSM map API 响应转换，89项（14建筑、60道路、3绿地、3水体、1体育、8POI）。采集范围 `[114.427,30.508,114.433,30.514]`；补充线段裁到 `[114.427,30.508,114.433,30.5122]`；完整多边形与孔洞保留。ODbL-1.0，© OpenStreetMap contributors。
- `artifacts/opto-campus-2026-10-29/exterior/reference-manifest.json`：API地址、原始XML哈希、下载文件时间、逐图URL和不确定性。
- `src/opto-building.js` 导出 `createOptoBuilding(THREE, record, {frame,geoToLocal})`，只匹配 `relation/13705821`。返回 `group`、`infrastructure`、`entry`、`viewpoints`、`dispose()`。
- `record` 使用现有 `createGeoScene` 的投影形状；楼体、三个内院和碰撞分割来自同一份轮廓。`infrastructure.replacedBuildingIds` 防止基础楼体重复挤出/挡住入口。
- C118入口是偏南西侧的**展示代理点** `[114.428111,30.508983]`，按 A—H 顺序作大致分区推断，**精确次入口位置未核实**。模型保留7.2米宽、4.4米高的地面凹口与前室，返回 `entry.evidenceStatus = display-estimate-unverified-secondary-entrance`。C118独立室内通过现有覆盖层进入，不捏造从这扇门到报告厅的完整走廊平面。
- 主入口雨棚对齐源庭院后沿，约 `[114.42860685,30.5093796]`；18级展示台阶连到2.82米平台。每级碰撞高度与显示几何相同。其级数和高度为照片比例建模值，非现场测量。
- 窗框、竖屏、屋面设备、Y形柱和台阶实例化；单楼预览约30个绘制调用、16.2万三角面，不含整校园。不是手机全场帧率实测。

运行时将补充FC与原FC合并，保留原坐标原点；拓展地面和游玩边界。相同道路ID在两份数据中可能分别保留南北裁剪片段，合并必须保留连接片段，不能只按ID丢弃补充线。不要把较大的源绿地外框当作新增可游玩范围。

## 本模块实际验证

- `node --test tests/opto-building.test.mjs`：5/5通过。检查精确建筑身份、三个内院、源码不可变、有限几何与实例预算；使用现有玩家运动实际走入次入口并爬主入口18级台阶，未跳到屋顶。
- IAB 打开 `http://127.0.0.1:5178/artifacts/opto-campus-2026-10-29/exterior/preview.html`，已查看鸟瞰、主入口、C118次入口，确认模型显示；截图位于同目录 `model-overview.png`、`model-main-entrance.png`、`model-c118-entry.png`。这是独立模型检视，不冒充整校园最后联调或公网部署。
- 根代理负责完整校园接入、南界与道路连接、C118覆盖层、整项目测试和最终浏览器验收。

本轮没有校方授权三维测绘数据、现状高程、完整楼层平面图或所有立面实拍。新增区域不是“完整东校区1:1测量复刻”的证明，缺失的证据不能由程序细节替代。
