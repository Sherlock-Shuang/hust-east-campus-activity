# 2026-10-28 手机界面整理

本次改动以已上线的镜头相对步行、移动速度和步态节奏为基线。校园与作品的存档、剧情通关条件和服务端权限没有改变。

- 过拟合恋人：手机端使用聊天、收藏、工作群、助手四个入口；聊天为单列布局，线索提示可收起，输入区跟随可见视口和安全区。各会话草稿分别保留，修复切换会话重启结尾计时、未读状态未刷新，以及部分剧情页被固定高度裁切的问题。作品编译产物来自独立 ta-say 源工程。
- 校园：G 对应的「定点弹射」直接显示在蜘蛛侠主动作区，显示瞄准状态；手机目标提示避开画质选择器，关闭更多动作、切入输入框和界面切换时释放旧触点。作品窗口在小屏全屏铺开，返回栏与软键盘可见区分开处理。
- 书境：增加移动摇杆、拖动镜头、翻书、闪避、手机和暂停入口；手机聊天去掉装饰外框，减少被遮住的三维背景渲染，初次进入不再等整包中文字库。
- 以撒：移动与射击双摇杆，确认、菜单、道具、炸弹和药丸按钮接入现有 Ruffle 输入。
- 晚言：触控动作接入原 Unity 按键；只在战斗显示移动摇杆，菜单、暂停、强化和重开阶段释放按住状态。

Unity、SWF、模型等原有二进制内容保持原字节。图书馆入口带发布版本查询；可变作品 JS/CSS 使用 no-cache，带内容哈希的校园与 ta-say 资源保持 immutable。
