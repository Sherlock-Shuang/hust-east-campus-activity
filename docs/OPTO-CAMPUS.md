# 光电大楼、爱因斯坦广场与 C118（2026-10-29）

本轮在既有校园上增量补建，没有重建移动系统。默认出生点仍为韵苑食堂。

## 使用

项目目录执行 `npm install`（首次），然后 `npm run dev`；打开 `http://127.0.0.1:5178/`。生产检查执行 `npm run build` 后 `npm start`。已有端口在运行时直接访问即可。

- `/?place=opto`：到达光电楼室内参观入口。步行靠近后按 Enter 或点击提示进入 C118。
- `/?place=opto-exterior`：光电楼入口外观。
- `/?place=einstein`：爱因斯坦广场。
- `/c118.html`：独立报告厅；`/c118.html?view=rear` 可从后排检查空间。

报告厅内 WASD 按镜头方向行走，Shift 加速，移动鼠标环视，L 锁定；触屏左侧落点为移动摇杆中心，右侧滑动环视。实现了标准手柄双摇杆映射，但本轮没有实体手柄/真实手机验收。顶部“返回校园”回到原位置和移动方式。主场操作提示与默认入口不变。

室内通过已有覆盖层及同源 iframe 桥按需载入。主场暂停、公告继续有效；关闭时通知子页释放资源并移除 iframe。室内参观不伪造作品打开、到访或完成事件，也不改变主持人开放的三个作品入口。

## 数据与模型

- `public/data/east-campus.geojson` 原文件不变，与此前已发布 `0e27776` 的 SHA256 相同。
- 新增 `public/data/opto-southeast.geojson`，运行时按稳定 ID 合并。重叠道路在原南界裁剪后只连接重合端点，不制造跨空隙的道路；每要素及全图包围盒重新计算。
- 实际新增 68 个唯一地图要素：12 个建筑、46 个道路、8 个 POI、1 个体育要素、1 个水体。总计 1152 项。
- 光电楼使用 `relation/13705821` 的原始轮廓与三个内院，约 33 米总高有校方公开文字支持；立面分格、局部退台仍属照片估计。旧数据范围没有包含这栋楼。
- 广场使用 `way/98865830` 范围，参考校方照片构造托颏头像、基座、白色廊架、台阶及灰红铺装，并排除随机植被。
- C118 参考真实报告厅活动照片构造弧形舞台、木饰面、双侧台阶、音箱、屏幕、排椅、侧门及可走通道。

**这不是测绘级的完整数字孪生。** C118 外门至报告厅的实际走廊未取得可配准平面图，入口使用明确的暂定点；22×34×9.6 米室内及 520 个展示座位是可配置估计。无逐树调查、完整楼层图或 DEM，不能把公开数据计数当成全校建筑台账。详见 [覆盖审查](east-campus-coverage-2026-10-29.md)。

## 维护

- 外观及暂定入口：`src/opto-building.js` 的 `OPTO_ACCESS`；碰撞体与可见几何共用计划。
- 室内尺寸：`src/opto-c118-interior.js` 的参数计划；不满足通道净宽的配置会报错。
- 广场：`src/einstein-square.js`；原始地图不写入估计雕塑坐标。
- 三栋/片区资料：[光电楼](opto-building-reference-2026-10-29.md)、[广场](einstein-square-reference-2026-10-29.md)、[报告厅](opto-c118-reference-2026-10-29.md)。研究照片只保存在本地 artifacts，不作为发布纹理。

光电楼远处隐藏细窗框/遮阳杆，保留楼体与宽玻璃带；广场模型合批并按距离隐藏细景。报告厅只创建一个活动 iframe，采用实例座椅、三张 128² 程序纹理，无动态阴影，退出后销毁。

## 验收记录

全量源码测试 734/734 通过。最终发布副本另跑与本次相关的几何、数据合并、移动、活动客户端测试；输出保存在本地 `artifacts/opto-campus-2026-10-29/`。

实际浏览器已验证：校园进入 C118、室内步行、连续三次进入/返回（每次 runtime_ready、返回后 iframe 数量为0、主场 suspended=false）、返回后 V 切视角及移动；广场平台实际走上与退下；独立模型的鸟瞰、外入口、报告厅后排视角。单元测试另验证门洞/座椅碰撞、两侧主过道、舞台台阶以及新旧道路连接。

部署沿用既有 GitHub → Vercel 项目，不使用 GPT 托管。新增 c118.html 已加入 Vite 多入口，补充 GeoJSON 随 public 打包；服务端与作品资源路由沿用当前发布版本。未发布的并行功能保留在原工作区，不在本次提交中混入。
