# C118 播放列表与入座使用说明

本文件说明 C118 播放列表、虚拟观众和入座功能。

## 影片

| 后台名称 | 固定媒体 ID | 时长 | 游戏播放文件 |
| --- | --- | --- | --- |
| Vibe Coding 成果展示 | `vibe-coding` | 1 分 52 秒 | `public/media/c118-vibe-coding-720p-v1.mp4` |
| AI 俱乐部宣传片 | `club-promo` | 1 分 37.53 秒 | `public/media/c118-club-promo-720p-v1.mp4` |

两片均为 1280 × 720、30 fps、H.264 / AAC 的 MP4，并启用 faststart。宣传片约 26.55 MiB，保留原片完整时长和原声音轨；Vibe Coding 集锦继续使用统一背景音乐。每片有独立 JPEG 封面，视频在大屏范围内等比显示。

进入报告厅先显示封面。播放器使用 `preload=none`，仅在报告厅可活动、页面可见且视线包含大屏时给视频赋源并加载；校园主场景不等待这两个视频。离厅、看向别处、全场暂停及海啸进行期间停止播放。未激活时收到换片只更新选择和封面，恢复观看后才加载最新影片。已缓冲的数据由浏览器管理，暂停不保证立即释放全部缓存。

## 主持人操作

登录 `/admin`，在「C118 大屏播放列表」选择影片后点击「播放所选」。厅内观众会收到同一选片指令，从头播放；「重新播放」让当前影片从头开始。普通公告、地图或暂停设置的更新不会重置影片。暂停期间可以选片，恢复后播放最新选择。

这是后台统一选片与重播，**不是帧级进度同步**。晚进入的观众从头观看所选片；网络、缓冲、视线暂停及观众个人操作可能使播放进度不同。观众可独立暂停、从头播放、开启或关闭声音；新的主持人播放指令会清除个人暂停，但保留个人声音设置。首次播放默认为静音；如浏览器拦截播放，观众可点击「播放」。

## 观众入座

- 点击「入座看大屏」进入第 3 排中区推荐座位；按 **E** 优先进入附近座位，附近没有合适座位时进入推荐座位。
- 入座后视角朝向舞台与大屏，默认横屏时画面中大屏宽度约占三分之二，可用鼠标或右侧滑动环视；「回看舞台」恢复观看方向。
- 按 **E** 或点击「起身」回到安全通道，再使用 WASD 或手机左侧触控移动。全场暂停期间禁止入座、起身和移动。

报告厅保留 **520 个座位，安排 203 名本地绘制的虚拟 NPC**，前排约 64%、中排约 36%、后排约 14%，以小组分散就坐。NPC 不代表真实在线玩家。玩家入座时仅在自己的画面中隐藏该座位的 NPC，起身后恢复；当前没有跨玩家座位预订、占座互斥或实时人物同步。后台真实在线人数仍来自原有参与者统计，与 NPC 数量无关。

## 报告厅控制与入口

三扇校园门使用各自的入口 ID，但统一按 `workId=opto-c118` 接收海啸和播放列表；从任何一扇门进入均接收主持指令。更新后需要刷新校园主页面，已打开的旧页面不会自动替换消息桥接代码。若当前海啸已结束涌入阶段，先恢复报告厅，再触发可从头演示。

## 发布与验收

沿用项目现有发布流程，同时发布前端、两片 MP4/JPEG 和服务端协议变更；保留现有活动数据库。媒体目录应以视频 MIME 类型提供文件并支持 HTTP Range。旧数据库缺少 `c118Screen` 时默认使用 Vibe Coding 集锦，无需清空数据。

本次通过 68 项相关自动检查和 `npm run build:vercel`；浏览器已验证从校园宿主左门进入后的切片和海啸、从东门穿门后接续水位、恢复报告厅后继续影片，以及第 3 排大屏视角。真实手机上的网络缓冲和帧率仍需现场确认。

## Codex 舞台大屏

后台选择「Codex 页面」或直接「发布到 Codex 大屏」，内容显示在与视频完全相同的 3D 屏幕上，使用相同的 16:9 适配。界面依据现有 `codex-ui-replica/dist/index.html` 和 `fidelity.css` 重建为 2560×1440 CanvasTexture，SVG 图标复用其 `icons.js`；不加载另一个应用或外部模型。主持文字实时同步，观众点击「回复大屏」只打开小输入框，输入与回复同时更新到自己画面中的舞台屏幕；不会上传回复。输入时冻结移动但继续按需绘制大屏。切回影片时收起输入框并恢复播放器；新旧贴图异步回调不会抢占另一种内容。
