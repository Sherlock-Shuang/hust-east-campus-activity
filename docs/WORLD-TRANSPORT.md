# 场景载具探索 · 2026-10-28

进入校园后默认从韵苑食堂步行出发。右上角为无底板操作文字。走近载具或战衣时，画面下方显示 F 交互提示；鼠标点击该提示也可使用。

## 操作

- 步行：W/S 前后，A/D 转向，Shift 快走。速度从 1.6 / 2.8 调整至 2.2 / 3.8 m/s，保留平滑加减速。
- 电动车：靠近任意当前停车区或车流中的电动车按 F。WASD 骑行，空格刹车；停稳按 F 下车。
- 特斯拉：WASD 驾驶；按住 Q 喷气飞行，松开后下落；空格刹车／切断推力；落地停稳按 F 下车。F 不再开关喷气。
- 直升机／飞行器：WASD 移动，Q/E 升降，空格减速／悬停；落地停稳按 F 退出。
- 蜘蛛侠：地面靠近战衣 F 穿上；E／鼠标左键长按保持同一锚点，松手后重按才换点。空格起跳／弹射，Q 收绳，X 俯冲，G 定点，T 空中特技。空中 F 保留前冲，地面 F 脱下。
- 游艇：岸边 F 登船，WASD 航行，Shift 加速，空格刹车。靠近可步行的岸边停稳 F 下船。岸线、岛屿、低桥及建筑会阻挡船体。
- 所有模式：鼠标环视，L 锁定／释放鼠标，V 切视角。Esc 先释放鼠标，再次按下退出至观察模式；点击“继续校园探索”返回当前角色。

## 场景配置与边界

`src/world-transport.js` 基于原米制地图规划 1 架韵苑草坪直升机、10 件地面战衣、3 辆路边汽车、5 架飞行器、2 艘东九湖游艇。可在 planWorldTransport 中调整路线比例和数量。放置会验证建筑、岸线、实际停车区、行人车辆和净空，不写入源 GeoJSON 或静态校园导出。

`src/scooter-transport.js` 复用所有当前渲染的电动车；借用时停止并移除原交通演员，下车留下原车型的一辆无人电动车。`src/transport-interaction.js` 管理拿取、归还、暂停边界与活动返回的库存认领。载具库存是每位观众自己的本地场景；不会争抢他人的载具，也不增加实时多人同步。

游戏物件不代表真实校园有飞机、喷气汽车或游艇。静态载具使用玩家模型共享材质，并按材质合并几何；21 件道具的模型提交数由 2107 减少到 169，远处裁减。离开体验仍由既有活动层处理暂停、返回和身份记录。

## 运行与发布

本地主项目：`npm install` 后 `npm run dev -- --port 5178`。入口 http://127.0.0.1:5178/ ，管理 http://127.0.0.1:5178/admin 。

部署副本位于 `deployment/vercel-app`：`npm test`、`npm run build:vercel`，推送已有 GitHub main 触发现有 Vercel 部署。没有更改管理员认证、活动开关、数据库凭据或活动记录。

## 本轮验证

- 使用实际地图、建筑设施、350 名交通演员和 228 辆停放电动车验证全部 21 个物件数量与完整净空。
- 用 120 Hz 实际运动模块，从出生点步行到最近的战衣、汽车和飞行器交互范围，均无阻挡。
- 生命周期测试覆盖重复上下车、拿取失败回滚、不重复生成、空中及高速退出限制、游艇靠岸、刷新认领。
- 浏览器实际验证默认步行、透明提示、F 穿上／脱下战衣、原有电动车骑行／下车；详见 output 下截图及验收记录。
- 完整测试与公网发布结果另记录于 output/world-transport-acceptance.json；未完成前不视为已上线。
