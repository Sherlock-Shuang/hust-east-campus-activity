# 校园墙面文字与诗

文字属于独立的活动装饰层，由正式校园入口的 `createCampus3D` 加载，不修改源 GeoJSON、建筑轮廓、碰撞、出生点或活动控制状态。

## 当前形式

2026-10-30 调整为更克制的环境题字：14 处原有 AI 文案保留内容和墙面落点，缩小尺寸、取消入口的实色底板，改为灰绿／石墨色的宋体字。食堂原有展示框仍保留。所有文字使用透明背景的哑光材质，跟随建筑光照，不能隔墙看到。AI 文案在 24–65 米间柔和淡出。

另有 10 组用户提供的中英文原句。根据“位置不要太隐蔽”的反馈，其中 6 处改到主食堂入口及东侧入口、光电楼进门第一段墙面、东九湖边道路和东十一临路墙带；其余保留体育馆等通行区的题字。逐句保留原始措辞、标点和大小写，包括“重心然诺”。中文使用宋体／楷体与竖排，英文使用衬线斜体及字间留白，配以呼吸线、羽毛、山水等少量线描；浅窄墙带使用单行题字。题字在 18–55 米间淡出，靠近重新显示，不新增地图光柱或提示牌。

当前合并地图共 24 块文字。使用静态 Canvas 纹理，无外部字体请求、新模型下载或逐帧纹理重绘。每帧仅做 24 次距离与透明度更新。

## 配置

- `src/campus-ai-murals.js`：原 AI 文案、统一透明材质、距离淡出及正式场景接入。
- `src/campus-poetry-art.js`：10 组原文、分行、字体与线描绘制。
- `src/campus-poetry-placements.js`：彩蛋的既有墙面、位置、正面方向、尺寸与检查站位。墙面必须同时有实体承托与可达视点，不能只依照 GIS 边线决定。新位置额外记录实际道路／入口上的 approach 视点与来源，检查经过时的视线。
- `src/activity-label-layout.js`：已有活动入口标签避开附近可见题字，已经淡出的文字不再让标签移位。不会移动主持人设定的光柱或入口。

正常入口仍从韵苑食堂出生。用于检查的 `?place=poem-<原文ID>` 读取墙面计划中的 inspection 视点；`?place=poem-<原文ID>-approach` 读取真实通行路线上的 approach 视点，验证从通常入口经过时的可见性。不改变默认出生，不在玩家界面公开题字列表。

## 验证

运行：

```sh
node --test tests/campus-ai-murals.test.mjs tests/campus-poetry-art.test.mjs tests/activity-label-layout.test.mjs
npm run build
```

测试覆盖正式场景接入、原 GIS 不变、入口尺寸与透明底、全部原句完整、生产纹理尺寸下绘制边界、10 处各 15 个背面承托射线和 15 个站位视线（共 300 条）、通行位置的可步行性与全幅视线、新旧题字不重叠、近远渐隐与再次靠近恢复、活动标签避让。Canvas 测试检查绘制命令及字体度量，不能替代浏览器的实际字体和像素验收。

浏览器另需检查默认出生点、正常道路及门口视点的题字可读性；不要只用贴墙近景代表通常漫游效果。发布走现有 GitHub → Vercel 流程，只同步本次文字相关源码；不上传参考资料或测试截图。
