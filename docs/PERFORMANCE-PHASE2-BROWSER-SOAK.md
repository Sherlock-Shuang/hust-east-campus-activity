# 真实 30 分钟浏览器帧会话验收

本轮 **通过**。2026-10-30 北京时间 **20:34:57.188–21:04:57.331**，实际计时 **1800.136 秒**，使用真实时间持续运行，没有快进时钟、刷新页面或缩短成快速测试。

## 条件与方法

- Apple M5 Mac，10 核、24 GiB 内存；Node **24.22.1**，实际安装的 Google Chrome **156.0.8078.76**，headless。
- 当前生产 `dist`，临时本地 Node 活动服务和独立数据目录；没有访问或写入生产活动数据库。
- 1280×720、设备 DPR 1；固定 **流畅档**，渲染预算像素比 0.85，绘制目标 30 fps。
- 默认韵苑食堂出生区，人物不移动，Playwright 每 100 ms 发送真实鼠标移动事件，持续左右及俯仰环视。场内 NPC、电动车等按原有仿真继续运动。
- 一次页面导航，同一页面、同一活动身份、同一帧会话；没有重载、切换作品或修改内部玩家状态。每分钟记录 canvas 帧统计、CDP JS heap、Documents、DOM 节点与监听器数量；每 5 分钟点击实际“导出性能报告”按钮，保存**不滚动清空的 frameSession**。
- 没有调用强制 GC，没有启用 GPU 查询。堆数据不是显存，也不是浏览器进程 RSS。

运行脚本：`scripts/soak-browser-runtime.mjs`。在本机 `deployment/performance-phase2-20261030/` 或对应 Git 部署仓库执行；本地复现使用 Node 24：

```sh
npm run build
/Users/another_dimension/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/soak-browser-runtime.mjs
```

脚本固定运行 30 分钟，记录中断为失败，退出时关闭 context、Chrome、本地服务并删除临时活动数据。

DOM 节点计数在 **2119–3519** 间波动，Documents 始终 1，监听器始终 420。没有观察到文档或监听器逐轮累积。Three.js 资源计数在 5／10／15 分钟为 1235／1238／1255 个 geometry，之后至第 30 分钟保持 1255；texture 始终 107。它们是对象数量，不等同于 GPU 显存占用或无泄漏证明。
