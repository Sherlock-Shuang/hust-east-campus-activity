# 2026-10-30 性能优化实施与验收

本轮基于 f296205 的既有校园进行增量优化，保留源地图、碰撞精度、120 Hz 物理、手动蛛丝锚点、步态、场景载具及主持人控制规则。发布时合并后续已发布内容，不覆盖并行开发。

## 已实施

| 部分 | 改动 |
| --- | --- |
| 建筑查询 | 共享 32 米空间索引，对步行/飞行扫掠、镜头、蛛丝遮挡先粗筛，再执行原精确判断；保持候选顺序 |
| 远景 | 在已有距离/视锥剔除与树木 LOD 上加入 10% 滞回，避免边界反复切换；导出与切画质清空历史 |
| 首次加载 | 校园构建分阶段让出主线程；步行不再等待蜘蛛侠；皮肤首次使用才构造，提前拾取等待并防止迟到切换 |
| C118 | 独立自动 DPR 与像素预算，水面/飞沫三档，NPC 15/20/25 Hz，静坐实例不逐帧上传 |
| 资源生命周期 | 退出作品中止预检，忽略旧 iframe 迟到 load；Unity 迟到注册立即销毁；触控定时器/手柄清理；室内实例缓冲释放 |
| 输入 | 按视口比例归一化触控，保存灵敏度/反转 Y/摇杆尺寸/减少晃动；设置关闭后恢复画布焦点 |
| 恢复 | 校园 WebGL 丢失时冻结，恢复时重建 PMREM；失败后可保留姿态重载；蜘蛛侠恢复等待皮肤准备；C118 支持 BFCache 返回 |
| 服务端 | SSE 公共状态同实例 500 ms 缓存与并发读取合并；认证、入场、CAS、身份及统计不缓存 |
| 验收工具 | 有界帧分布、长帧和启动分阶段计时；可导出诊断报告；实际源数据的路线回放与独立压测脚本 |

所有移动判定仍使用完整轻量碰撞世界。当前远景主要减少绘制，尚未完成整个校园按街区加载/释放。异步构建的 8 ms 是让出调度目标，单个大阶段仍可能数百毫秒；不能称为完全消除启动阻塞。

## 已完成的测量

- 完整 `npm test`：658/658，通过。另有活动副本生命周期与资源映射定向测试，见资源审计文档。
- 17 段真实源路线 × 6 种帧时间设置 = 102/102，通过；包括桥上/桥下、食堂店廊、CBD、东九和光电三个门。它是分段物理回放，不替代完整人工路线。
- 同机同轮 CPU 基准：步行查询耗时降低 26.1%，飞行 37.0%，蜘蛛侠 22.0%，镜头 70.9%，蛛丝遮挡 71.6%；新旧输出哈希一致。这些不是 FPS 增幅。
- C118 流畅档水体三角形 26,240 → 4,096（约减少 84%）；NPC 600 帧 CPU 中位约 555 → 334 ms。干燥时矩阵更新范围 263,872 → 15,232 字节；不等同于显存驻留减少。
- 步行初始化角色属性缓冲约 14.61 → 9.09 MB；无 Worker 回退基准明显改善，正常 Worker 路径未测得 CPU 启动收益，不宣称首屏已加速 30%。
- 100 个合成观众、两个真实 serverless handler、本地隔离 SQLite，第二轮实际运行 30 分钟：12,425 请求、630 次自然 SSE 轮换、90 次刻意重连，0 错误/重试，独立/在线人数均 100；主持状态接收 P95 约 1.59 秒。首轮约 19 分钟发生未定位 HTTP 失败，日志保留。该测试不代表 100 台 3D 设备或生产 Turso 网络。

## 浏览器验证

本机 Chromium、1280×720、均衡档；本地生产构建和真实 HTTP 资源。真实进入图书馆三维场景、晚言 Unity 场景及过拟合恋人聊天/朋友圈流程，各 10 轮进入和返回；每轮返回后 iframe 数为 0、校园未保持暂停，焦点回到画布。没有发送伪造就绪或通关事件。

校园的真实 `WEBGL_lose_context` 测试已恢复画面，状态回到 ready，记录一次丢失，未出现控制台 error。这是一次应用恢复验证；不能据此保证所有设备图形驱动均能恢复。浏览器观察到的几何/纹理对象数量不等于实际 GPU 内存；本轮未取得跨运行时显存堆和音频硬件测量。

最终发布及 C118 浏览器补充结果见文档末尾。

## 使用与复测

日常在右上角选择“自动”或“流畅优先”；“操作”按钮可调灵敏度、摇杆和镜头晃动。无需改原有按键。

验收时在校园地址加 `?diagnostics=1`，点击“导出性能报告”；只有 localhost 显示“测试画面恢复”。报告只包含设备/帧与资源计数，不上传身份和凭据。恢复按钮会故意触发一次画面暂停，只用于验收。

部署仓库：`npm ci` → `npm run build:vercel`。本地项目继续原 `npm run dev`；服务器 SSE 缓存和 `scripts/soak-activity-local.mjs` 属于 Vercel 部署仓库，不要求把整套 serverless 复制进本地 Node 项目。

```sh
npm test
node scripts/benchmark-building-queries.mjs
node scripts/verify-campus-route-matrix.mjs
node scripts/benchmark-c118-runtime.mjs
node scripts/soak-activity-local.mjs --seconds 1800 --audiences 100 --output artifacts/soak.json
```

长期测试只创建隔离临时数据库，不读取生产凭据。生产不做百人写入压测。

## 仍需真实设备与素材工程的项目

- 尚无旧集显电脑、中端 Android、iPhone 的 20–30 分钟热降频实测、实体手柄验收或现场 Wi-Fi 彩排；不能把桌面窗口尺寸变化当作通过。
- 尚未证明整体“首屏 -30%”或“典型视角 draw calls -25%”目标。现有合批/距离剔除继续生效，本轮主要降低查询、构建连续阻塞与室内视觉工作。
- 图书馆主模型 127.9 MB，约 94.15% 为几何，线上大资源已有 Brotli；真正进一步减小需要几何简化、分区及 LOD 资产流程。仅重复 gzip 不会解决主问题，本轮未破坏性改写 GLB/Unity 编译数据。
- 不将本轮性能改动称为新增全校实景还原或统一视频帧同步。
