# 地图与交互一致性修复

本轮针对可复现的视觉／碰撞及状态冲突增量修复。源 GeoJSON、投影坐标、建筑外观和载具数量不变。

## 修复范围

- 桥墩、桥侧栏杆从同一套渲染参数导出碰撞体；桥下不再穿墩，桥上栏杆不会变成桥下的墙。
- 喻岱桥渲染的混凝土肩带和步道加入显式跨水支撑；普通台阶不获得跨水许可。
- 镜头复用局部障碍空间索引，避开桥墩和护栏；远处障碍不参与局部射线。
- 由源建筑分块构成的复合楼，碰撞保留实际分块与可见低基座，去除未渲染的整块父轮廓实体。实证验证计算机与人工智能大楼及 `relation/20970638` 的两处空区；体育馆原疑似点位于真实分块内部，仍保持阻挡。
- 借车同时校验距离、所在层和人与载具之间的路径；上下船只豁免水面间隙，不豁免围栏。失败归还原载具，不复制或丢失库存。预置载具以地面层为高度参考，避免生成在上方高架。
- 低架空建筑下上台阶时，按脚点／轮胎抬升后的全身高度校验净空，避免先穿入楼板再卡住。
- 活动返回通过运动层的原子恢复接口，校验当前地图、边界与占位；无效返回保留当前位置并归还新认领的物品。合法返回同步内部飞行速度、视角与近裁剪面，不回填可能过期的原始相机坐标，不自动续挂旧蛛丝。

专项回归覆盖真实桥墩、双侧喻岱桥步道、车道／桥下层、实体隔挡上下车、真实湖岸上下船、低净空台阶、飞行状态恢复、库存一致性、旧输入释放与局部镜头碰撞。浏览器验收页使用真实地图与正式运动／镜头函数，发送正常移动输入；它不等同于全场多人负载测试。
