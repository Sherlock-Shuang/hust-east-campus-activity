# 摆荡与主持人活动开启更新

2026-10-28。

后续操作调整：摆荡已改为完全手动换点，一次按下至多一根蛛丝；松手后再次按下才重新挂点。下述上摆和停滞自动换点机制已移除。低空收绳、直丝以及主持人活动开启功能继续保留。

## 摆荡

旧版会因挂点落到身后或超过 3 秒直接松丝；可见蛛丝又用辅助物理支点的绳长计算下垂，导致受力时也出现大弯曲。本轮将可见绳线改为使用真实松弛量，弯垂上限 18 厘米，受力时绷直。

连续按住 E／鼠标左键时，提前收绳保护离地净空，提高起步力度，缩短接丝放绳过渡。普通自动换丝需要离地至少 8 米、向上速度超过 1.8 米/秒且从本次低点上升至少 2 米；没有新挂点时，只有 12 米以上的上摆允许短暂腾空寻找后续挂点。安全墙边停滞恢复另要求至少 7 米净空、实际侧向挂点及视线畅通，通过短时加速度引导离墙，WASD 输入优先。建筑遮挡仍会中断不可行的绳线，手动松丝与俯冲仍有效。

保留原校园碰撞、地图、角色、相机和按键。低楼辅助物理支点是原有玩法机制；可见端点始终位于实际建筑，不增加天空挂点。

## 活动开启

控制台 → 活动开启 → 勾选作品 → 开启所选活动。支持多选，一次提交同时设置光柱和入口；未选作品关闭。全部关闭会撤下作品光柱与入口，不影响独立集合标记或阶段。已有 iframe 不强退；仍在请求进入、尚未建立 iframe 的观众会取消进入。关闭后可继续记录既有作品的打开／返回，不能新增到访或进入。

新场次默认全关，已存在场次由持久化状态决定。重新部署不会清空观众或重置主持人的操作。进入作品仍应从校园点位完成；这些开关控制校园活动入口，不是针对静态作品 URL 的保密访问系统。
