### 校园加载、绘制与驻留

- 完整基础地面、建筑轮廓、桥层、碰撞及门洞先就绪，出生区外观准备好后允许行走；其余立面、森林及装饰分片补齐。取消、返回和重新建图均拒收过期任务。完整导出仍使用全量构建路径。
- 拆分铺装像素生成、树木规划、路缘及前场绿化的同步任务。新增保守空间筛选，补齐路侧树的画质预算；实例数组按当前需要分配，冷却后缩容。
- 低档进入作品时释放通用立面、森林的装饰实例缓冲；返回按当前视野恢复。逻辑和远景保留，共享几何、纹理与源描述仍在，**这不是全校园纹理流式卸载**。
- 校园和 C118 限制实际绘制到 30/60 Hz，高刷显示器不再无上限提交；输入、物理与活动时钟继续独立更新。容忍 RAF 亚毫秒时间抖动，避免 60 Hz 屏误跳帧。
- C118 视频观影采用 30 Hz 绘制，补齐初始化/绘制失败清理、返回、视频与音频销毁。进入其他作品释放室外洪水和海啸资源，返回按活动当前时间恢复。保留主分支刚新增的各档卷浪、喷雾和雾效。
- 诊断包含首个绘制提交、下一 RAF 观察到的首帧、首个输入变化、完整细节完成、实际绘制率、会话直方图及有界分钟记录。GPU 查询仅在显式开启时运行，扩展不可用时返回 null，不以 CPU render 时间冒充 GPU 时间。

### 活动服务

- SSE 校时只发送时间，不再为每个连接反复执行全场 COUNT。展示人数短缓存并合并同时发起的查询；入场上限、身份、权限和探索事件仍实时校验。
- 观众心跳错峰为 22.5–27.5 秒，单标签只允许一个心跳在途，保留同人多标签去重与原掉线期限。
- 本地 Node 将非关键在线状态的磁盘写入合并至最多每秒一次；到访、打开、返回仍持久化后确认，进程正常关闭会 flush。
- 慢 SSE 消费者队列有上限，断开后重连读取最新状态；故障诊断仅含阶段、错误代码和随机关联号，不记录身份、SQL、密钥或 URL。

### 真实 30 分钟连续渲染

同一实际 Chrome 页面，固定流畅档、韵苑出生区持续环视，实际运行 1,800.136 秒，没有刷新、假时钟或强制 GC。非滚动会话共 53,998 次绘制，平均 29.9765 FPS，P95/P99 直方图上界均为 34 ms；超过 100 ms 的长帧累计 3 次。会话包含开测前的14个间隔/1.2秒，其中已有1次长帧，正式计时段新增2次。30次每分钟检查Documents始终为1，零脚本错误、零模型/运行资源错误（仅favicon图标404），结束后测试资源关闭。记录包含六份每五分钟的完整会话报告及首末截图。

期间另一次公网验收与模型弱网测试存在短暂并行图形负载，动态车流和环视可见量也会变化，因此不以开始/结尾 CPU 差异声称热稳定收益。后约十分钟没有额外 GPU 测试。这仍是本机桌面测试，不是中低端手机或全图最高速路线的半小时结果。条件、内存波动和时间区间见 [30 分钟原始会话验收](PERFORMANCE-PHASE2-BROWSER-SOAK.md)，原始数据位于 `artifacts/performance-phase2/browser-soak-30m/`。
