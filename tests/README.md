# 服务端验收测试

在仓库根目录执行 `npm ci && npm test`。现有 test 脚本 `node --test tests/*.test.mjs` 即可运行，无需修改生产配置。

测试直接导入 `serverless/`、校园领域逻辑及作品代理。数据库为临时目录中的本地 libSQL SQLite；每个场景使用两个独立客户端模拟多个函数实例，结束时清理数据库、连接与定时器。不访问远程 Turso，不需要 `.env` 或真实凭据，也不调用外部模型。

覆盖匿名身份恢复和同名区别、同人多标签去重、Origin/CSRF 与管理员权限、状态 revision CAS、进入失败和幂等事件、共享模型调用限额、100 位观众及 100 条 SSE 连接的统计，以及实际 Node HTTP 包装器的路径重写、JSON、cookie、查询参数和断连清理。

SSE 240 秒到期测试使用注入时钟推进完整生命周期，不等待真实 4 分钟。压测输出属于本机 API/SQLite 环境，不能代替公网 Turso 性能、真实浏览器或 100 个三维画面的验收。
